React(TSX)에서 파이썬의 .pop(index)이나 del list[index]처럼 특정 인덱스의 요소를 삭제할 때는 .filter() 메서드를 사용하는 것이 가장 깔끔하고 일반적입니다.
.filter()는 기존 배열을 수정하지 않고, 조건에 맞는 요소들만 추려내어 새로운 배열을 반환하기 때문에 리액트의 불변성을 완벽하게 지켜줍니다.
## 💡 가장 많이 쓰는 구현 방법 (.filter())
배열의 두 번째 인자인 현재 요소의 인덱스(i)가 내가 삭제하려는 인덱스(targetIndex)와 같지 않은 것들만 남기는 방식입니다.

import { useState } from 'react';
export default function App() {
  const [list, setList] = useState<string[]>(['사과', '바나나', '오렌지', '포도']);

  const handleDelete = (targetIndex: number) => {
    // 인덱스가 targetIndex와 일치하지 않는 요소만 남김
    setList(list.filter((_, i) => i !== targetIndex));
  };

  return (
    <div>
      <ul>
        {list.map((item, index) => (
          <li key={index}>
            {item} 
            {/* 클릭한 항목의 인덱스를 넘겨서 삭제 */}
            <button onClick={() => handleDelete(index)}>삭제</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

------------------------------
## 🛠️ 대안: 다른 구현 방법들
상황이나 코드 스타일에 따라 아래의 방식들도 사용할 수 있습니다.
## 1. 최신 문법 toSpliced() 사용하기
앞서 insert에서 보았던 toSpliced()를 삭제에도 쓸 수 있습니다. 두 번째 인자(삭제할 개수)를 1로 주면 해당 인덱스의 요소가 깔끔하게 제거된 새 배열이 반환됩니다.

const handleDelete = (targetIndex: number) => {
  // targetIndex부터 1개의 요소를 제거한 새 배열 반환
  setList(list.toSpliced(targetIndex, 1));
};

## 2. slice() 조합하기
배열을 삭제할 대상을 기준으로 앞, 뒤 두 조각으로 자른 뒤 합치는 방식입니다.

const handleDelete = (targetIndex: number) => {
  setList([
    ...list.slice(0, targetIndex),
    ...list.slice(targetIndex + 1)
  ]);
};

------------------------------
## 📌 요약 및 팁

* 인덱스로 삭제할 때: list.filter((_, i) => i !== index) 조합이 리액트에서 가장 표준적인 코드입니다.
* id(고유값)로 삭제할 때: 실제 프로젝트에서는 인덱스 대신 데이터가 가진 고유 id로 삭제하는 경우가 더 많습니다. (예: list.filter(item => item.id !== targetId))

혹시 배열의 요소를 삭제할 때 특정 값(예: '바나나')을 찾아서 삭제해야 하거나, 고유한 ID를 기반으로 삭제해야 하는 구조인가요? 필요하신 데이터의 형태를 알려주시면 상세히 도와드릴게요!
