React(TSX)에서 파이썬의 .insert(index, 값)처럼 특정 위치에 요소를 삽입할 때도 배열의 불변성을 지켜야 합니다.
가장 세련되고 자주 쓰이는 방법은 JavaScript의 .slice() 메서드와 스프레드 연산자(...)를 조합하는 것입니다. 삽입할 위치(index)를 기준으로 배열을 두 조각으로 자른 뒤, 그 사이에 새 값을 넣는 방식입니다.
## 💡 가장 많이 쓰는 구현 방법

import { useState } from 'react';
export default function App() {
  const [list, setList] = useState<string[]>(['사과', '바나나', '포도']);

  const handleInsert = (index: number, newValue: string) => {
    // index 위치에 newValue를 삽입
    setList([
      ...list.slice(0, index), // 1. 처음부터 index 전까지 자르기
      newValue,                // 2. 새 값 삽입
      ...list.slice(index)     // 3. index부터 끝까지 자르기
    ]);
  };

  return (
    <div>
      {/* 1번 인덱스(바나나 앞)에 '오렌지' 삽입 */}
      <button onClick={() => handleInsert(1, '오렌지')}>
        1번 자리에 오렌지 넣기
      </button>
      <ul>
        {list.map((item, index) => <li key={index}>{index}: {item}</li>)}
      </ul>
    </div>
  );
}

------------------------------
## 🛠️ 대안: 가독성이 좋은 toSpliced() 사용하기 (추천)
최근 JavaScript(ES2023)에 추가된 .toSpliced() 메서드를 사용하면 파이썬 문법과 가장 유사하고 깔끔하게 작성할 수 있습니다. 기존 배열을 건드리는 .splice()와 달리, 원본을 그대로 두고 새 배열을 반환하므로 리액트에서 쓰기 완벽합니다.

const handleInsert = (index: number, newValue: string) => {
  // 인자 설명: (시작인덱스, 삭제할 개수, 추가할 값)
  setList(list.toSpliced(index, 0, newValue));
};

※ 주의: 아주 오래된 브라우저나 구버전 Node.js 환경에서는 지원하지 않을 수 있어, 안전하게 사용하려면 첫 번째 slice 방식을 더 권장합니다.
------------------------------
## ⚠️ 주의: 기존 .splice()는 사용 금지

// ❌ 절대 금지 (원본 배열을 직접 수정함)
list.splice(index, 0, newValue);
setList(list);

.push()와 마찬가지로 .splice() 역시 원본 배열 데이터를 직접 변경하므로 리액트가 상태 변화를 감지하지 못해 화면이 리렌더링되지 않습니다.
만약 배열 안에 있는 데이터가 단순 문자열이 아니라 ID를 가진 객체 배열({ id: 1, name: '사과' })인가요? 아니면 혹시 여러 개의 값을 동시에 삽입해야 하는 상황인지 알려주시면 그에 맞는 코드를 바로 작성해 드릴게요!
