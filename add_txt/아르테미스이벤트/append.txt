React(TSX)에서는 파이썬의 .append()처럼 배열에 값을 추가할 때, 기존 배열을 직접 수정하지 않고 스프레드 연산자(...)를 사용해 새로운 배열을 만들어 상태를 업데이트해야 합니다.
리액트는 불변성(Immutability)을 유지해야 화면을 올바르게 리렌더링하기 때문에, JavaScript의 .push()를 직접 사용하면 상태 변화를 감지하지 못합니다.
## 💡 가장 많이 쓰는 구현 방법 (스프레드 연산자)

import { useState } from 'react';
export default function App() {
  // string 타입의 배열 상태 선언
  const [list, setList] = useState<string[]>(['바나나', '사과']);

  const handleAppend = () => {
    // 파이썬의 list.append('오렌지')와 같은 효과
    setList([...list, '오렌지']);
  };

  return (
    <div>
      <button onClick={handleAppend}>추가하기</button>
      <ul>
        {list.map((item, index) => <li key={index}>{item}</li>)}
      </ul>
    </div>
  );
}

------------------------------
## 🛠️ 다양한 방식 비교
상황에 따라 아래의 방식을 골라 사용할 수 있습니다.
## 1. 이전 상태를 안전하게 참조할 때 (함수형 업데이트)
상태 업데이트가 연속으로 일어나거나 최신 상태를 보장해야 할 때는 prev 인자를 사용합니다.

setList(prevList => [...prevList, '오렌지']);

## 2. 배열의 맨 앞에 추가하고 싶을 때 (파이썬의 .insert(0, 값))
스프레드 연산자의 위치만 바꾸면 맨 앞에 요소를 추가할 수 있습니다.

setList(['오렌지', ...list]);

## 3. 기존 자바스크립트의 .concat() 사용
.concat() 메서드는 기존 배열을 건드리지 않고 새 배열을 반환하므로 리액트에서 안전하게 사용할 수 있습니다.

setList(list.concat('오렌지'));

------------------------------
## ⚠️ 주의: 왜 .push()는 안 되나요?

// ❌ 절대 금지 (화면이 바뀌지 않음)
list.push('오렌지'); 
setList(list); 

list.push()는 메모리 상의 배열 주소값은 그대로 둔 채 내부 데이터만 바꿉니다. 리액트는 "배열의 주소값이 바뀌었는가?"로 변경 여부를 판단하므로, 위와 같이 작성하면 값이 추가되어도 화면에 나타나지 않습니다.
현재 어떤 데이터 타입(객체 배열 등)을 추가하려고 하시나요? 구현 중인 데이터 구조를 알려주시면 TSX 타입 정의를 포함한 맞춤형 코드를 안내해 드릴게요!
