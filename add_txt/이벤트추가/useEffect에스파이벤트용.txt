배열로 해놓고, 에스파 멤버일 때 클릭했을 때 당첨 배열에 10개 해놓고, 
10개 이후에 당첨 아님 나오게.

React와 TypeScript(TSX) 환경에서 setInterval을 사용해 1초마다 숫자를 1씩 증가시키는 가장 올바른 예제 코드입니다. [1] 
리액트에서 타이머를 쓸 때는 클로저(Closure)로 인한 상태 고정 문제를 방지하기 위해 setCount 내부에서 함수형 업데이트(prev => prev + 1)를 사용해야 하며, 컴포넌트가 사라질 때 타이머를 종료하는 정리(Cleanup) 함수를 반드시 반환해야 합니다. [1, 2, 3] 
## 📝 예제 코드 (Counter.tsx)

import React, { useState, useEffect } from 'react';
export default function Counter(): React.JSX.Element {
  // 숫자를 저장할 상태 정의
  const [count, setCount] = useState<number>(0);

  useEffect(() => {
    // 1초(1000ms)마다 실행되는 타이머 생성
    const intervalId = setInterval(() => {
      // 이전 상태값(prev)을 기반으로 1씩 증가 (클로저 문제 방지)
      setCount((prevCount) => prevCount + 1);
    }, 1000);

    // 컴포넌트가 언마운트(삭제)될 때 타이머를 정리(Clear)
    return () => {
      clearInterval(intervalId);
    };
  }, []); // 빈 의존성 배열을 넣어 컴포넌트 마운트 시 최초 1회만 실행

  return (
    <div style={{ padding: '20px', textAlign: 'center' }}>
      <h1>실시간 카운터</h1>
      <p style={{ fontSize: '2rem', fontWeight: 'bold' }}>{count}</p>
    </div>
  );
}

## 💡 핵심 포인트 설명

* 
* 함수형 업데이트 (prevCount => prevCount + 1)
* setCount(count + 1)로 작성하면 useEffect가 처음 실행될 때의 count 값(0)만 기억(클로저 현상)하여 숫자가 1에서 더 이상 증가하지 않습니다.
   * 반면 prevCount를 매개변수로 받는 함수형 업데이트를 쓰면 항상 가장 최신의 상태값을 가져와 올바르게 1씩 증가합니다. [1, 2, 4] 
* 클린업 함수 (return () => clearInterval(intervalId))
* 컴포넌트가 화면에서 사라지거나 재렌더링될 때 기존 타이머를 제거하지 않으면 메모리 누수(Memory Leak)가 발생하거나 타이머가 중복되어 숫자가 제멋대로 빠르게 올라갑니다. [1, 3] 
* 의존성 배열 []
* 배열을 비워두어야 컴포넌트가 처음 나타날 때 타이머가 딱 한 번만 등록되어 안정적으로 구동됩니다. [1, 4]
