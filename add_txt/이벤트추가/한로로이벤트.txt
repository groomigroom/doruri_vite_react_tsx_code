문자열 배열 뒤집기

결론부터 말씀드리면, React(TSX)에서는 for문보다 배열의 내장 메서드(reverse, join)를 사용하는 것이 훨씬 더 직관적이고 효율적입니다.
React는 선언형(Declarative) 프로그래밍을 지향하기 때문에, UI 내부에서 복잡한 for문 루프를 돌리는 것보다 데이터 변환 메서드를 체이닝하는 것이 가독성에 좋습니다.
아래에서 추천하는 방법과 구체적인 예시 코드를 확인해 보세요.
## 💡 추천하는 방식: 내장 메서드 활용
한 글자 문자열 8개를 역순으로 뒤집은 뒤, 하나의 p 태그 안에 통째로 넣고 싶다면 reverse()와 join()을 사용하시면 됩니다.

import React from 'react';
export default function ReverseText() {
  const chars = ['한', '글', '자', '문', '자', '열', '들', '요'];

  // 원본 배열을 복사한 뒤 역순으로 뒤집고 하나의 문자열로 합칩니다.
  const reversedText = [...chars].reverse().join('');

  return (
    <div>
      <p>{reversedText}</p>
    </div>
  );
}

## ⚠️ 주의할 점 ([...chars]를 쓴 이유)
자바스크립트의 .reverse() 메서드는 원본 배열을 직접 변경(Mutation)합니다. React에서는 상태(State)나 원본 데이터를 직접 수정하는 것을 피해야 하므로, 전개 연산자(...)를 사용해 배열을 안전하게 복사한 뒤 역순으로 정렬하는 것이 좋습니다.
## ❓ 왜 for문보다 좋을까요?

* 코드 가독성: for문은 인덱스 변수를 만들고 조건을 지정해야 해서 코드가 길어지지만, 메서드 체이닝은 "뒤집고 합친다"는 목적이 한눈에 보입니다.
* 불변성 유지: 복사 후 처리하는 방식이 React의 데이터 흐름 템플릿과 잘 맞습니다.
