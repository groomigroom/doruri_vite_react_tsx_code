HTML에서 display: flex를 설정한 부모 div 내부의 자식 div들이 반응형(화면 줄어듦)일 때 가로 폭이 줄어드는 이유는 Flexbox의 기본 속성인 flex-shrink가 1로 설정되어 있기 때문입니다.
flex-shrink: 1은 화면 공간이 부족해질 때, 자식 요소들이 자신의 원래 크기를 유지하지 않고 부모의 너비에 맞춰 스스로 줄어들도록 만듭니다.
이를 해결하고 자식 div들의 가로 폭을 고정하거나 원하는 대로 제어하는 방법은 다음과 같습니다.
------------------------------
## 💡 해결 방법## 1. 자식 요소들의 크기를 고정하고 싶을 때 (flex-shrink: 0)
화면이 작아지더라도 내부 div들의 가로 폭이 절대 줄어들지 않고, 원래 크기(예: width: 200px)를 유지하게 하려면 자식 요소에 flex-shrink: 0을 부여해야 합니다.

.parent {
  display: flex;
}

.child {
  width: 200px;
  flex-shrink: 0; /* 화면이 줄어들어도 내 크기를 유지함 */
}

## 2. 아래 줄로 자연스럽게 떨어지게 하고 싶을 때 (flex-wrap: wrap)
반응형 웹을 만들 때 가장 많이 쓰는 방법입니다. 부모 너비가 좁아지면 자식 요소들이 줄어드는 대신, 다음 줄로 자연스럽게 넘어가도록 만듭니다.

.parent {
  display: flex;
  flex-wrap: wrap; /* 자식들이 박스 너비를 초과하면 다음 줄로 넘김 */
}

.child {
  width: 200px; /* 각 자식의 기본 너비 */
}

------------------------------
## 🔍 속성 한눈에 비교하기

| 속성명 | 기본값 | 반응형 화면에서의 역할 |
|---|---|---|
| flex-shrink | 1 | 공간이 부족할 때 요소가 줄어드는 비율을 결정 (0으로 하면 안 줄어듦) |
| flex-grow | 0 | 공간이 남을 때 요소가 늘어나는 비율을 결정 |
| flex-basis | auto | 요소의 기본 크기를 설정 (width와 유사하지만 flex 방향에 영향받음) |

------------------------------
원하시는 반응형 레이아웃의 형태(우측으로 스크롤 생성, 아래 줄로 줄바꿈 등)를 알려주시면, 그에 맞는 정확한 CSS 코드 예시를 더 자세히 안내해 드리겠습니다.
