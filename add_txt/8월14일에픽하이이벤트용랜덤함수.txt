React + TypeScript(TSX)에서 4가지 함수 중 하나를 랜덤으로 실행하는 가장 깔끔한 방법은 함수들을 배열로 묶고, 랜덤 인덱스를 생성해 실행하는 것입니다.
다음은 바로 사용할 수 있는 간단한 컴포넌트 예시입니다.

import React from 'react';
export default function RandomExecutor() {
  // 1. 실행할 4가지 함수 정의
  const actionOne = () => console.log('첫 번째 함수 실행!');
  const actionTwo = () => console.log('두 번째 함수 실행!');
  const actionThree = () => console.log('세 번째 함수 실행!');
  const actionFour = () => console.log('네 번째 함수 실행!');

  // 2. 함수들을 배열로 그룹화
  const functionsArray = [actionOne, actionTwo, actionThree, actionFour];

  // 3. 랜덤 실행 함수 정의
  const runRandomFunction = () => {
    // 0부터 3까지의 랜덤 정수 생성
    const randomIndex = Math.floor(Math.random() * functionsArray.length);
    
    // 선택된 함수 실행
    functionsArray[randomIndex]();
  };

  return (
    <div style={{ padding: '20px', textAlign: 'center' }}>
      <h3>랜덤 함수 실행기</h3>
      <button onClick={runRandomFunction}>
        랜덤 함수 호출하기
      </button>
    </div>
  );
}

## 💡 핵심 포인트

* Math.random(): 0 이상 1 미만의 부동소수점을 반환합니다.
* functionsArray.length: 배열의 크기(4)를 곱해 0이상 4미만의 수로 만듭니다.
* Math.floor(): 소수점을 버려서 정확히 0, 1, 2, 3 중 하나의 정수 인덱스를 얻습니다.
