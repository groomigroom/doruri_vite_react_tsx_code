React(TSX) 환경에서 일반 Class 
객체(도메인 모델 또는 비즈니스 로직 캡슐화)를 
정의하고 상태(State)와 연동하여 사용하는 
정석적인 예시입니다.

React는 기본적으로 불변성(Immutability)을 기반으로 변경 사항을 감지하므로, 클래스 인스턴스의 내부 값만 바꾸면 리렌더링이 일어나지 않습니다. 따라서 인스턴스를 복사하거나 새로운 객체를 만들어 상태를 업데이트해야 합니다. [reddit](https://www.reddit.com/r/reactjs/comments/yb5uaa/class_in_typescript_use_for_what/?tl=ko) [1, 2, 3]

## 1. Class 정의하기 (Todo.ts)
데이터 구조와 관련 메서드를 포함하는 순수 TypeScript 클래스를 작성합니다. [codesign](https://codesign.tistory.com/213)

// Todo.tsexport class Todo {
  id: number;
  text: string;
  isCompleted: boolean;

  constructor(id: number, text: string, isCompleted: boolean = false) {
    this.id = id;
    this.text = text;
    this.isCompleted = isCompleted;
  }

  // 완료 상태를 반전시키는 메서드
  toggleComplete(): void {
    this.isCompleted = !this.isCompleted;
  }

  // React 상태 변경을 위해 자기 자신을 복사한 새 인스턴스를 반환하는 메서드
  clone(): Todo {
    return new Todo(this.id, this.text, this.isCompleted);
  }
}

## 2. React 컴포넌트에서 사용하기 (App.tsx)
위에서 정의한 클래스를 가져와 useState와 함께 다룹니다. [4] 

// App.tsximport React, { useState } from 'react';import { Todo } from './Todo';
export default function App() {
  // 1. 초기값으로 Class 인스턴스 배열 생성
  const [todos, setTodos] = useState<Todo[]>([
    new Todo(1, 'React 공부하기'),
    new Todo(2, 'TypeScript 클래스 활용하기'),
  ]);
  const [inputText, setInputText] = useState('');

  // 2. 새로운 인스턴스를 추가하는 함수
  const handleAddTodo = () => {
    if (!inputText.trim()) return;
    const newTodo = new Todo(Date.now(), inputText);
    setTodos([...todos, newTodo]); // 불변성을 지키기 위해 새 배열로 지정
    setInputText('');
  };

  // 3. 기존 인스턴스의 메서드를 실행하고 상태를 업데이트하는 함수
  const handleToggleTodo = (id: number) => {
    const updatedTodos = todos.map((todo) => {
      if (todo.id === id) {
        todo.toggleComplete(); // 내부 값 변경
        return todo.clone();   // ⭐ 새로운 인스턴스를 반환하여 React가 변경을 감지하도록 함
      }
      return todo;
    });
    setTodos(updatedTodos);
  };

  return (
    <div style={{ padding: '20px' }}>
      <h2>Todo 리스트 (Class 객체 활용)</h2>
      <input 
        value={inputText} 
        onChange={(e) => setInputText(e.target.value)} 
        placeholder="할 일을 입력하세요"
      />
      <button onClick={handleAddTodo}>추가</button>

      <ul>
        {todos.map((todo) => (
          <li 
            key={todo.id} 
            onClick={() => handleToggleTodo(todo.id)}
            style={{ 
              textDecoration: todo.isCompleted ? 'line-through' : 'none',
              cursor: 'pointer' 
            }}
          >
            {todo.text} {todo.isCompleted ? '✅' : '❌'}
          </li>
        ))}
      </ul>
    </div>
  );
}

## 💡 핵심 요약 및 주의할 점

* 
* 클론 메서드(clone()) 필수: React는 todo.isCompleted = true와 같이 내부 프로퍼티만 바꾸면 메모리 주소가 그대로여서 화면을 다시 그리지 않습니다. 변경 후 반드시 새 인스턴스로 복사(얕은 복사 또는 새 new 객체 생성)해 주어야 합니다. reddit
* 비즈니스 로직 분리 장점: 데이터와 관련된 연산(toggleComplete 등)을 컴포넌트 내부가 아닌 클래스 메서드로 격리할 수 있어 코드가 깔끔해지고 단위 테스트(Unit Test)를 만들기 쉬워집니다.
* 상태 관리 라이브러리 연동: 만약 복사 과정(clone)이 번거롭고 클래스 객체의 반응형 동작을 더 쉽게 구현하고 싶다면 MobX나 Valtio 같은 상태 관리 도구를 결합하여 사용하는 것이 실무에서 권장됩니다. until.blog reddit
