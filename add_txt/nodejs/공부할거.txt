4. Express 공식 사이트

[Express.js 공식 문서](https://expressjs.com/?utm_source=chatgpt.com)

지금 질문하신 목적이 Spring Boot → Node.js/Express로 넘어가는 것이라면 특히 추천합니다.

Spring과 비교하면 대략:

Spring Boot	Node.js + Express

@Controller	router.get()
@GetMapping()	app.get()
@PostMapping()	app.post()
@RequestParam	req.query
@PathVariable	req.params
@RequestBody	req.body
Model	res.render()에 데이터 전달
Thymeleaf	EJS 등
Filter/Interceptor	Middleware
Spring Security	Passport.js 등


예를 들어 Spring에서

@GetMapping("/products/{id}")
public String product(@PathVariable Long id, Model model) {
    ...
    return "product";
}

하는 것을 Express에서는 대략

app.get("/products/:id", (req, res) => {
    const id = req.params.id;

    res.render("product", {
        id: id
    });
});

처럼 구현합니다.

5. Node.js + Express를 제대로 따라 해보고 싶다면

지금 배우고 계신 Spring Boot + Thymeleaf와 연결해서 공부한다면 저는 이 순서를 추천합니다.

Node.js 공식 Learn → JavaScript/비동기 → Express → EJS → MySQL/MongoDB → REST API → 로그인/인증 → React + Node.js

특히 최근에 질문하셨던 객체 데이터를 /name 같은 URL로 라우팅하고 EJS 페이지를 만드는 것을 공부하려면

> Node.js → Express → EJS → Router → REST API



이 순서가 가장 직접적으로 도움이 됩니다.

원하시면 제가 Spring Guide처럼 "Node.js 입문 → Express → EJS → DB → 로그인"까지 예제가 단계별로 연결되는 학습 사이트/튜토리얼만 골라서 추천해드릴 수도 있습니다.
