가능합니다. 지금처럼 **조건부 렌더링으로 다음 input이 나타나는 순간 자동으로 focus를 이동**시키려면 `useRef`와 `useEffect`를 사용하는 방법이 가장 깔끔합니다.

핵심은:

1. 각각의 input에 `ref`를 연결
2. 값이 `'l'`, `'e'`, `'m'`처럼 변경될 때 `useEffect` 실행
3. 다음 input이 나타나면 `.focus()` 실행

### 1. `useRef`, `useEffect` 추가

```tsx
import { useEffect, useRef, useState } from "react";
```

### 2. 각 input의 ref 만들기

```tsx
const aespa_e_ref1 = useRef<HTMLInputElement>(null);
const aespa_e_ref2 = useRef<HTMLInputElement>(null);
const aespa_e_ref3 = useRef<HTMLInputElement>(null);
const aespa_e_ref4 = useRef<HTMLInputElement>(null);
const aespa_e_ref5 = useRef<HTMLInputElement>(null);
const aespa_e_ref6 = useRef<HTMLInputElement>(null);
const aespa_e_ref7 = useRef<HTMLInputElement>(null);
const aespa_e_ref8 = useRef<HTMLInputElement>(null);
```

그리고 값이 바뀌었을 때 다음 input으로 이동시킵니다.

```tsx
useEffect(() => {
    if (aespa_e_value1 === "l") {

```

그리고 input에 `ref`를 연결합니다.

```tsx
<input
    ref={aespa_e_ref1}
    type="text"
    name="aespa_e_value1"
    value={aespa_e_value1}
    onChange={(e) => setAespa_e_value1(e.target.value)}
/>

{aespa_e_value1 === 'l' && (
    <input
        ref={aespa_e_ref2}
        type="text"
        name="aespa_e_value2"
        value={aespa_e_value2}
        onChange={(e) => setAespa_e_value2(e.target.value)}

```

이런 식으로 각각 연결하면 됩니다.

### 전체적으로 보면

```tsx

    const [aespa_e_value3, setAespa_e_value3] = useState<string>("");

    const [aespa_e_value8, setAespa_e_value8] = useState<string>("");
```

### 그런데 한 가지 더 중요한 부분

현재 코드는 `input`에 **한 글자만 입력하도록 제한하지 않았습니다.**

예를 들어 첫 번째 input에 `lemonade`를 한꺼번에 입력할 수도 있습니다. 이 이벤트가 **한 칸에 한 글자씩 입력하는 게임/이벤트**라면 다음처럼 `maxLength`를 넣는 것을 추천합니다.

```tsx
<input
    ref={aespa_e_ref1}
    type="text"
    maxLength={1}
    value={aespa_e_value1}
    onChange={(e) => setAespa_e_value1(e.target.value)}
/>
```

그리고 각 input에도 `maxLength={1}`을 넣으면 됩니다.

그러면 사용자가

**`l` 입력 → 2번 input 생성 → 커서 자동 이동 → `e` 입력 → 3번으로 이동 → ... → `e` 입력 → 당첨**

이라는 흐름이 정확하게 만들어집니다.

추가로 원한다면 **틀린 글자를 입력했을 때 자동으로 첫 번째 칸으로 돌아가게 하는 기능**도 쉽게 붙일 수 있습니다.
