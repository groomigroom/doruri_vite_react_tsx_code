useEffect(() => {
        timeoutRef.current = setTimeout(() => {
            setCurrentIndex((prev) => prev + 1);
        }, 3000);

        return () => {
            if (timeoutRef.current) clearTimeout(timeoutRef.current);
        };
    }, [currentIndex]); 위 react tsx 부분의 의미?




이 코드는 3초마다 currentIndex 값을 1씩 자동으로 증가시키는 "무한 반복 타이머(자동 슬라이드 등)" 기능입니다.
currentIndex가 바뀔 때마다 기존 타이머를 안전하게 지우고 새 타이머를 실행하는 방식으로 동작합니다.
------------------------------
## 코드의 핵심 동작 과정 (한 단계씩 보기)

   1. 최초 렌더링 (또는 currentIndex 변경 시)
   * useEffect 내부 코드가 실행됩니다.
      * setTimeout이 실행되면서 3초 뒤에 currentIndex를 +1 시키는 예약 작업이 등록됩니다.
      * 이때 생성된 타이머의 식별자(ID)가 timeoutRef.current에 저장됩니다.
   2. 3초 후 (타이머 완료 시)
   * setCurrentIndex((prev) => prev + 1)이 호출되면서 상태가 바뀝니다.
      * 상태가 바뀌었으므로 컴포넌트가 리렌더링됩니다.
   3. 리렌더링 직후 (정리 단계)
   * currentIndex 변수가 변경되었으므로 useEffect가 다시 실행되려고 합니다.
      * 이때 새 타이머를 켜기 직전, return () => { ... }(클린업 함수)가 먼저 호출됩니다.
      * clearTimeout(timeoutRef.current)를 통해 방금 끝난(또는 남아있는) 이전 타이머를 메모리에서 깨끗하게 지웁니다.
   4. 반복
   * 다시 1번으로 돌아가서 새 타이머를 등록하고 3초를 기다립니다.
   
------------------------------
## 왜 이렇게 작성했을까요? (이 코드의 장점)

* 메모리 누수(Memory Leak) 방지: 만약 사용자가 3초가 지나기 전에 페이지를 떠나거나 컴포넌트가 화면에서 사라지면(Unmount), return 내부의 clearTimeout이 실행되어 백그라운드에서 타이머가 혼자 돌아가는 것을 막아줍니다.
* 정확한 타이밍 보장: 의존성 배열([currentIndex])에 값이 들어있기 때문에, 상태가 바뀔 때마다 타이머를 완전히 새로 고침(Reset)하여 시간 오차를 줄입니다.
