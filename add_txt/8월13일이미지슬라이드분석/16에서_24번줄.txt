제공해주신 코드는 React와 TypeScript에서 일정 시간마다 인덱스를 자동으로 증가시키는 타이머 기능을 구현한 코드입니다. 주로 이미지 슬라이더, 배너 롤링, 캐러셀(Carousel) 등에서 많이 사용됩니다.
이해가 쉽도록 각 줄이 무슨 역할을 하는지 하나씩 자세히 풀어서 설명해 드릴게요.
------------------------------
## 1. useEffect(() => { ... }, [currentIndex]);

* 역할: currentIndex 값이 변경될 때마다 내부에 있는 함수(효과)를 실행합니다.
* 상세: useEffect는 컴포넌트가 화면에 나타나거나(마운트), 의존성 배열([ ])에 넣은 값이 바뀔 때 실행되는 리액트 훅(Hook)입니다. 여기서는 currentIndex가 바뀔 때마다 타이머를 새로 구동하는 역할을 합니다.

## 2. timeoutRef.current = setTimeout(() => { ... }, 3000);

* 역할: 3초(3000ms) 후에 코드를 실행하는 타이머를 작동시키고, 그 타이머의 ID를 저장합니다.
* 상세:
* setTimeout은 브라우저에게 "3초 뒤에 이 함수를 실행해줘"라고 요청하는 함수입니다.
   * 이때 브라우저는 이 타이머를 구별할 수 있는 고유한 번호(ID)를 반환합니다.
   * 그 ID를 timeoutRef.current라는 저장 공간에 기록해 둡니다. 나중에 이 타이머를 취소(clear)하고 싶을 때 이 ID가 필요하기 때문입니다. [1, 2] 

## 3. setCurrentIndex((prev) => prev + 1);

* 역할: 3초가 지나면 현재 인덱스 값에 1을 더해 다음 상태로 업데이트합니다.
* 상세:
* setCurrentIndex는 상태(State)를 변경하는 함수입니다.
   * 이전 값(prev)을 받아와서 prev + 1을 반환하는 함수형 업데이트 방식을 사용했습니다. 이 방식은 항상 가장 최신의 상태 값을 안전하게 가져와서 계산해 줍니다. [3, 4] 

## 4. return () => { ... }; (클린업 함수)

* 역할: 다음 타이머가 켜지기 직전이나, 컴포넌트가 화면에서 사라질 때 기존 타이머를 청소(취소)합니다.
* 상세: useEffect 안에서 return하는 함수를 '클린업(Cleanup) 함수'라고 부릅니다. 리액트에서 매우 중요한 개념으로, 메모리 누수나 버그를 방지하기 위해 사용합니다. [5, 6] 

## 5. if (timeoutRef.current) clearTimeout(timeoutRef.current);

* 역할: 저장해 둔 타이머 ID가 있다면, 그 타이머의 작동을 취소합니다.
* 상세: currentIndex가 바뀌면 useEffect가 다시 실행되는데, 이때 이전 실행에서 켜두었던 3초짜리 타이머를 끄지 않으면 타이머들이 겹쳐서 오작동하게 됩니다. 따라서 새 타이머를 켜기 전에 clearTimeout으로 이전 타이머를 깔끔하게 지워주는 것입니다. [7] 

------------------------------
## 💡 요약하자면 이 코드는 이렇게 작동합니다

   1. 처음 화면이 켜지거나 currentIndex가 바뀌면 "3초 뒤에 인덱스 1 올리기" 예약(타이머)을 겁니다.
   2. 3초가 지나면 실제로 인덱스가 1 올라갑니다.
   3. 인덱스가 바뀌었으므로 리액트가 이전 타이머를 취소(클린업)하고, 다시 1번으로 돌아가 새로운 3초 타이머를 켭니다.
   4. 이 과정이 무한히 반복되며 3초마다 인덱스가 자동으로 증가합니다. [8, 9] 

------------------------------
현재 이 코드는 인덱스가 끝없이 증가하도록 되어 있습니다. 만약 슬라이더의 마지막 이미지에 도달했을 때 처음(0번)으로 되돌리는 기능이나 자동 재생을 일시 정지하는 기능을 추가하고 싶으신가요? 필요하시다면 해당 기능을 추가한 완성형 코드를 안내해 드릴게요.
