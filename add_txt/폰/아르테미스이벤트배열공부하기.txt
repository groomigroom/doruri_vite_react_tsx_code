React TSX에서 값이 변할 때 화면도 같이 바뀌는 배열을 만들려면 useState 훅과 제네릭(< >)을 써서 타입을 지정하면 됩니다. 직접 수정(push 등) 대신 전개 연산자(...)로 새 배열을 만들어 넣습니다.tsximport { useState } from 'react';

// 문자열 배열 상태 만들기
const [items, setItems] = useState<string[]>([]);

// 값 추가하기 (새 배열 생성)
const addItem = (newItem: string) => {
  setItems([...items, newItem]);
};
코드를 사용할 때는 주의가 필요합니다.배열 상태 관리 핵심 방법타입 지정: useState<타입[]>(초기값) 형태로 배열 안의 데이터 타입을 정합니다. (예: number[], 객체형태면 인터페이스 지정)값 추가: 기존 배열을 복사한 뒤 새 항목을 붙여서 업데이트 함수에 넣습니다.값 삭제: filter 메서드를 써서 특정 조건의페이지만 제외한 새 배열을 만듭니다.값 변경: map 메서드를 써서 원하는 인덱스의 값만 바꾼 새 배열을 만듭니다.
